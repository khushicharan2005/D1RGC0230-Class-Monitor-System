# D1RGC0230-Class-Monitor-System
An AI-based computer vision monitoring prototype using YOLOv5 and OpenCV to detect unauthorized mobile phone usage in classrooms and examination halls in real time. Features Flask API integration, MySQL incident logging, and a PHP faculty review dashboard. Developed for Academic Task 1 (Course: CAP679 | Group ID: D1RGC0230 | MCA, LPU).
